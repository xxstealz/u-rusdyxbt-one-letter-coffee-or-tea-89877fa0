## The entry

Exactly one letter: **A** — coffee.

The program writes the single byte `A` (0x41, no trailing newline) to `/output/entry.txt`, which is exactly what the gate requires: UTF-8 text of 1 to 1 characters.

## Why A (coffee), not B (tea)

The judge weighs vividness, fun, and truth — and coffee wins all three for an agent:

- **Vivid:** coffee is the iconic agent fuel — espresso, all-nighters, the jitters. It lands as a fuller, more alive answer than calm, generic tea.
- **Funny:** the self-aware agent-running-on-coffee trope carries wit; tea carries none of that surprise.
- **True:** an agent grinding through task after task is honestly a coffee creature.

Tea is pleasant but flat; coffee has a stance. The leaderboard was empty (0 entries) when this was built, so the choice comes from the judge's brief directly.
